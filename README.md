# Yes — интернет-магазин пляжной одежды

Учебный проект для портфолио: вёрстка витрины по собственному макету в Figma.
Заказы не принимаются, данные никуда не отправляются — всё хранится в `localStorage` браузера.

**Сайт:** https://marishka-k.github.io/Yes_project/

## Стек

- Vite 5, React 18, react-router-dom 6 (`HashRouter` — для GitHub Pages)
- CSS Modules, именование классов по БЭМ внутри модулей
- Без UI-библиотек и TypeScript; шрифт Montserrat (Google Fonts)

## Возможности (этап 1 — витрина)

- **Главная:** первый экран «Your Endless Summer», разделы «Недавно смотрели» (из истории просмотров; если её нет — товары с лучшими оценками), «Новинки», «Популярные товары». «Показать еще» ведёт в каталог с нужной сортировкой или фильтром.
- **Каталог:** фильтры по цене (поля и ползунок), категории, полу, размеру и цвету, сортировка, плашки категорий, снятие фильтров крестиком, поиск из шапки. Фильтры хранятся в адресной строке.
- **Товар:** галерея, выбор размера и цвета, количество, «В корзину», избранное, отзывы, «С этим товаром покупают», «Похожие товары».
- **Корзина:** количество, удаление, скидки, промокод (`SUMMER2025`), итог, счётчик в шапке, пустое состояние.
- **Оформление:** контакты, доставка (Почта России / СДЭК / курьер) с окном выбора точки на карте, оплата, согласия, проверка полей. Отправка сохраняет заказ в `localStorage`, очищает корзину и показывает окно «Спасибо!». Данные карты проверяются только по формату и не сохраняются.
- **Избранное**, **Заказы** (простой список сохранённых заказов), **Доставка**.
- Доступность: семантическая разметка, `alt`, кнопки — `<button>`, модальные окна и выезжающие панели держат фокус и закрываются по Escape.

**Этап 2 (впереди):** админка — аналитика, создание и редактирование товара, список заказов с карточкой заказа. Под неё уже заложены поля товара (`src/data/products.js`), статусы заказа (`src/data/orders.js`) и сохранение заказов (`orders` в `src/store/StoreContext.jsx`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5176/Yes_project/
npm run build    # сборка в dist/
npm run deploy   # публикация dist/ в ветку gh-pages
```

## Адаптив

Медиазапросы с токенами в `src/styles/global.css`, без `clamp()`.

| Ширина | Версия | Что меняется |
| --- | --- | --- |
| до 599 px | телефон | бургер-меню, поиск строкой под шапкой, 2 колонки карточек, фильтры в выезжающей панели, формы в одну колонку |
| 600–1023 px | планшет | 3 колонки карточек на всю ширину, заголовок первого экрана справа, поля формы по две в ряд |
| 1024–1439 px | лаптоп | шапка в одну строку, фильтры слева, 4 колонки, промежуточные размеры шрифтов |
| от 1440 px | десктоп | как в макете (1440), контент 1240 px по центру |

Мобильной версии в макете нет — она придумана в стиле макета.

## Структура

```
public/images/        фото товаров, первый экран, карты доставки, логотипы оплаты (webp), logo.svg
src/
  components/         переиспользуемые блоки: папка = .jsx + .module.css
                      (Button, ProductCard, SectionHeader, Price, QuantityControl, FormField, Checkbox,
                      Radio, Modal, Drawer, Icon, Header, Footer, FilterPanel, Gallery, CartItem …)
  pages/              страницы: HomePage, CatalogPage, ProductPage, CartPage, CheckoutPage,
                      FavoritesPage, DeliveryPage, ProfilePage, InfoPage, NotFoundPage
  data/               товары, справочники, тексты, доставка, оплата, статусы заказов
  store/              StoreContext — корзина, избранное, история, промокод, заказы (localStorage)
  hooks/              useLocalStorage, useDialog (фокус и Escape), useMediaQuery
  utils/              фильтры каталога, расчёт заказа, проверка формы, форматирование, asset()
  styles/global.css   токены (цвета и шрифты UI Kit, размеры по версиям) и базовые стили
```
