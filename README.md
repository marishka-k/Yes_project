# Yes — интернет-магазин пляжной одежды

Учебный проект для портфолио: витрина и админка по собственному макету в Figma.
Заказы не принимаются, данные никуда не отправляются — всё хранится в `localStorage` браузера.

**Сайт:** https://marishka-k.github.io/Yes_project/

## Стек

- Vite 5, React 18, react-router-dom 6 (`HashRouter` — для GitHub Pages)
- CSS Modules, именование классов по БЭМ внутри модулей
- Без UI-библиотек и TypeScript; шрифт Montserrat (Google Fonts)

## Возможности (этап 1 — витрина)

- **Главная:** первый экран «Your Endless Summer», разделы «Недавно смотрели» (из истории просмотров; если её нет — товары с лучшими оценками), «Новинки», «Популярные товары». «Показать еще» ведёт в каталог с нужной сортировкой или фильтром.
- **Каталог:** фильтры по цене (поля и ползунок), категории, полу, размеру и цвету, сортировка, плашки категорий, снятие фильтров крестиком, поиск из шапки. Фильтры хранятся в адресной строке.
- **Товар:** галерея, выбор размера и цвета, количество, «В корзину», избранное, отзывы, «С этим товаром покупают», «Похожие товары».
- **Корзина:** количество, удаление, скидки, промокод (`SUMMER2025`), итог, счётчик в шапке, пустое состояние.
- **Оформление:** контакты, доставка (Почта России / СДЭК / курьер) с окном выбора точки на карте, оплата, согласия, проверка полей. Отправка сохраняет заказ в `localStorage`, очищает корзину и показывает окно «Спасибо!». Данные карты проверяются только по формату и не сохраняются.
- **Избранное**, **Заказы** (простой список сохранённых заказов), **Доставка**.
- Доступность: семантическая разметка, `alt`, кнопки — `<button>`, модальные окна и выезжающие панели держат фокус и закрываются по Escape.

## Админка (этап 2 — сделан)

**Как войти:** «Личный кабинет» (иконка профиля) → «Перейти в админку», в мобильном меню — пункт «Админка (демо)», или сразу `#/admin`:
https://marishka-k.github.io/Yes_project/#/admin. Авторизации нет — это демо-режим, о чём говорит плашка вверху.

- **Аналитика → График продаж:** период «Месяц / Год», месяц и год; SVG-график без библиотек (линии «Количество заказов» и «Количество возвратов» по дням или месяцам, оси со стрелками, подсказки при наведении, таблица для экранных читалок) и итоги «Оформлено / Выполнено / Возвращено / В работе / Отменено».
- **Данные для графика:** заказы с витрины (`yes:orders`) + демо-заказы с 01.01.2025 по сегодня (`src/data/demoOrders.js`). Демо-заказы генерируются детерминированно (генератор mulberry32, зерно = дата + SEED): при каждом открытии одни и те же номера, клиенты и суммы. В `localStorage` попадают только изменённые статусы. Демо-заказы можно отключить в «Настройке».
- **Каталог товаров:** активные и архивные товары, фильтр по категории, поиск по названию и коду, удаление (с подтверждением), «Скрыть» в архив / «Вернуть» из архива, постраничный вывод.
- **Добавить / Изменить товар:** все поля макета, проверка (артикул — уникальные 6–13 цифр, название, справочники, цена, скидка меньше цены, хотя бы один цвет и фото). Кнопка «+» добавляет значение справочника (категория, коллекция, состав, подкладка, цвет с оттенком, размер). Фото выбираются из картинок, которые уже есть на сайте, — загрузки файлов нет (сайт статический). Описание из формы показывается на странице товара.
- **Витрина = базовые товары (`src/data/products.js`) + правки админки** (`src/store/CatalogContext.jsx`): созданные и изменённые товары сразу видны в каталоге, на главной и на странице товара; архивные и удалённые не показываются.
- **Заказы:** «В работе» (оформлен, передано в доставку, в пути, ожидает в пункте выдачи), «Выполненные», «Возвраты» (возвраты и отмены); фильтр по статусу, поиск, карточка заказа: состав, детали доставки со шкалой статусов, покупатель и оплата, смена статуса заказа и оплаты. Итоги аналитики пересчитываются сразу, статус заказа с витрины меняется и в личном кабинете.
- **Пользователи:** покупатели собраны из заказов (по e-mail), «Активные» и «Черный список» (пометка для менеджера, на витрину не влияет).
- **Настройка:** показ демо-заказов, сброс каталога, статусов демо-заказов и чёрного списка.

Ключи `localStorage` админки: `yes:admin:products`, `yes:admin:archived`, `yes:admin:deleted`, `yes:admin:dictionaries`, `yes:admin:settings`, `yes:admin:demo-orders`, `yes:admin:blacklist`.

Мобильной версии админки в макете нет: меню разделов открывается бургером в шапке, таблицы до 1023 px превращаются в карточки «подпись: значение», форма товара — в один столбец (фото сверху). Код админки загружается отдельным чанком только при входе в `/admin`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5176/Yes_project/
npm run build    # сборка в dist/
npm run deploy   # публикация dist/ в ветку gh-pages
```

## Адаптив

Медиазапросы с токенами в `src/styles/global.css`, без `clamp()`.

| Ширина | Версия | Что меняется |
| --- | --- | --- |
| до 599 px | телефон | бургер-меню, поиск строкой под шапкой, 2 колонки карточек, фильтры в выезжающей панели, формы в одну колонку |
| 600–1023 px | планшет | 3 колонки карточек на всю ширину, заголовок первого экрана справа, поля формы по две в ряд |
| 1024–1439 px | лаптоп | шапка в одну строку, фильтры слева, 4 колонки, промежуточные размеры шрифтов |
| от 1440 px | десктоп | как в макете (1440), контент 1240 px по центру |

Мобильной версии в макете нет — она придумана в стиле макета. В админке на лаптопе боковое меню 260 px, на десктопе — 288 px, как в макете.

## Структура

```
public/images/        фото товаров, первый экран, карты доставки, логотипы оплаты (webp), logo.svg
src/
  components/         переиспользуемые блоки: папка = .jsx + .module.css
                      (Button, ProductCard, SectionHeader, Price, QuantityControl, FormField, Checkbox,
                      Radio, Modal, Drawer, Icon, Header, Footer, SiteLayout, FilterPanel, Gallery, CartItem …)
    admin/            блоки админки: AdminLayout, AdminHeader, AdminSidebar, AdminPage, AdminPageHead,
                      SalesChart, StatTile, DataTable, Pagination, StatusBadge, IconButton, ProductForm,
                      ProductPhotos, ImagePicker, ScrollList, AddOptionModal, ConfirmModal, AdminNotice,
                      OrderComposition, OrderTimeline
  pages/              страницы витрины: HomePage, CatalogPage, ProductPage, CartPage, CheckoutPage,
                      FavoritesPage, DeliveryPage, ProfilePage, InfoPage, NotFoundPage
    admin/            AdminApp (маршруты /admin), SalesPage, ProductsPage, ProductEditPage,
                      OrdersPage, OrderPage, UsersPage, SettingsPage
  data/               товары, справочники, тексты, доставка, оплата, статусы заказов,
                      меню и справочники админки, демо-заказы (demoOrders.js)
  store/              StoreContext — корзина, избранное, история, промокод, заказы;
                      CatalogContext — товары витрины с правками админки; AdminContext — данные админки
  hooks/              useLocalStorage, useDialog (фокус и Escape), useMediaQuery, useElementSize, usePaged
  utils/              фильтры каталога, расчёт заказа, проверка форм, аналитика, форматирование, asset()
  styles/global.css   токены (цвета и шрифты UI Kit, размеры по версиям) и базовые стили
```
